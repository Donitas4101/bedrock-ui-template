# My UI Template

This repo is a starter template for a Minecraft Bedrock resource pack that visually mimics a custom pause menu and mod panel.

Important:
- This is a visual UI template only.
- It does not include real world logic or gameplay scripting.
- To make it fully functional, you would need a Behavior Pack / scripts.

Structure:
- `ui/` contains the JSON screen definitions.
- `texts/` contains language strings.
- `textures/` is ready for PNG button, background, toggle, and icon assets.

How to use:
1. Download the ZIP.
2. Extract it.
3. Rename the extracted folder to something like `MyCustomUI.mcpack`.
4. Import it into Minecraft Bedrock.
5. Enable it in your resource pack settings.

Notes:
- The JSON files are intentionally easy to edit.
- Replace the placeholder icon and button textures with your own PNGs.
- Use the example screens as a base for a custom UI style.
